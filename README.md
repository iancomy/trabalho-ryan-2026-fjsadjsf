Falllllaaa ai Ryanzinho! eu to aqui pra falar sobre esse projeto que é só uma introdução breve e fácil de como usar efetivamente a 
Programação Orientada a Objetos!! 
O projeto que eu, Yan Vitor, do Segundo DS II escolheu foi o número 1, caso não seja obvio pelo código!!!

O programa foi desenvolvido usando de duas classes::: a main, que é responsável pela execução do usuário e a classe aluno, que pode armazenar 
os dados do aluno e sua situação academica!!

O programa usa de ambos atributos privados como público para permitir o acesso a informações!!!

Para funcionar, o usuário informa o nome e a nota do aluno, em seguida, o sistema cria um objeto da classe (aluno) e tenta seguir as regras
contidas no objeto para ver se o aluno vai reprovar ou não! nesse caso, a linha a qual os alunos infelizmente não seguirão seus anos felizes
e contente é 7.

O site usado pra fazer esse código foi o Intellij, que foi o único que eu lembro do senhor usar em aula.
